# Bhojanalay Nivas

A Swiggy-inspired food ordering platform built using modern Java microservices and React.

## Tech Stack

### Backend
- Java 21
- Spring Boot
- Spring Security
- Spring Cloud Gateway
- PostgreSQL
- JWT
- Docker

### Frontend
- React
- Vite
- Redux Toolkit
- Tailwind CSS
